XRT Toolkit
===========

GPU X-ray transforms and basic reconstruction, compiled with `Dr.Jit
<https://drjit.readthedocs.io>`_.

Getting started
---------------

The notebooks ``tutorial_2D.ipynb`` and ``tutorial_3D.ipynb`` in the repository
root cover the forward and adjoint operators, arbitrary and structured
geometries, reconstruction, and differentiation with respect to the
acquisition geometry.
