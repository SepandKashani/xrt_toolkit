Citing this work
================

If the library helped your research, please cite it.

Software
--------

The repository carries a ``CITATION.cff`` file. GitHub reads it, so the
*Cite this repository* button gives you a formatted entry.

.. code-block:: bibtex

   @software{xrt_toolkit,
     title  = {XRT Toolkit},
     author = {Kashani, Sepand and Haouchat, Youssef},
     url    = {https://github.com/SepandKashani/xrt_toolkit},
     year   = {2026},
     note   = {Version 2.0.0}
   }

Paper
-----

A paper describing the library is in preparation:

   Y. Haouchat, S. Kashani, P. Thévenaz, M. Unser and A. Boquet-Pujadas,
   *XTK: a fast differentiable library for tomographic projections with
   arbitrary geometries*.

Please cite the paper once it appears, and the software entry above meanwhile.

What to cite alongside
----------------------

The kernels compile through Dr.Jit [jakob2022drjit]_. If you use ``fbp`` or
``fbp_cone``, the filters follow Kak and Slaney [kak1988]_ and Feldkamp, Davis
and Kress [feldkamp1984]_. Full entries are in the :doc:`bibliography`.
