Tutorials
=========

The notebooks live in the repository root and appear here with the outputs
they were run with. You can run them yourself.

``tutorial_2D.ipynb`` covers the forward and adjoint operators, arbitrary and
structured geometries, reconstruction, and fitting the geometry by gradient
descent. ``tutorial_3D.ipynb`` covers parallel and cone-beam scans in 3-D.

Problem sizes and the basis order are variables at the top of each notebook.
